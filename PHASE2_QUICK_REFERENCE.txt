PATTERNS FIXED
================================================================================

Pattern 1: echo $variable;
  → echo esc_html($variable);

Pattern 2: echo '<p>' . $var . '</p>';
  → echo '<p>' . esc_html($var) . '</p>';

Pattern 3: value="<?php echo $var; ?>"
  → value="<?php echo esc_attr($var); ?>"

Pattern 4: href="<?php echo $url; ?>"
  → href="<?php echo esc_url($url); ?>"

Pattern 5: printf('%s', $var);
  → printf('%s', esc_html($var));

Pattern 6: echo $html_content;
  → echo wp_kses_post($html_content);
